# Dra. Ana Laís Rigolon

Crie uma landing page (single page) para a Dra. Ana Laís Rigolon, médica especialista em obesidade, emagrecimento e nutrologia, em Piracicaba-SP.

CONTEXTO E OBJETIVO

- Público: mulheres que já tentaram emagrecer sozinhas e não conseguiram manter o resultado

- Ação principal do site: levar o visitante a clicar em um botão de WhatsApp

- Objetivo do site: gerar contatos qualificados e transmitir credibilidade médica (site atual: nenhum)

- Quebrar a objeção de custo/tempo: deixar claro que não é solução rápida/milagrosa, e sim acompanhamento sério e baseado em ciência

ESTILO VISUAL (provisório — identidade visual final ainda não definida)

- Direção: premium, sofisticado, clean, confiável, seguro — nunca apelativo ou "vendedor"

- Paleta provisória: azul-marinho + off-white + rosa blush/nude, com detalhes discretos em dourado/champagne — use variáveis CSS/tokens de cor centralizados (fácil de trocar depois)

- Tipografia: combinar uma serifada elegante para títulos com uma sans-serif limpa para corpo de texto

- Evitar: qualquer estética de "promessa milagrosa", cores vibrantes, gamificação, elementos que pareçam anúncio de emagrecimento genérico

IMAGENS

- Ainda não temos as fotos profissionais da médica — use placeholders de imagem (retângulos com ícone de pessoa, ou imagem de banco de imagens neutra) em todos os espaços destinados a fotos dela

- Marque claramente no código onde cada imagem entra (comentário tipo // PLACEHOLDER: foto hero, // PLACEHOLDER: foto sobre)

MOVIMENTO (leve, sutil, sem exagero)

- Fade + slide sutil ao rolar (scroll reveal) nos textos e cards

- Hover com leve elevação (shadow + translateY) nos cards de serviços

- Micro-pulse discreto no botão principal de WhatsApp

- Transições suaves no accordion do FAQ (não abrir/fechar
